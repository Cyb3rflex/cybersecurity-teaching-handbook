# Module 10: Modern Cybersecurity

> **Canonical Module ID**: `SEC-MOD10`  
> **Course Level**: Advanced  
> **Total Estimated Duration**: 10 Hours  
> **Prerequisites**: Modules 1 through 9

---

## 1. Module Overview & Pedagogical Scope
The cybersecurity landscape has undergone a profound shift away from perimeter-based firewalls toward cloud-native ecosystems, microservices, containerization, and distributed identity models. This capstone module exposes students to the frontiers of modern defensive and operational security.

Key subjects include the Cloud Shared Responsibility Model (IaaS, PaaS, SaaS), container runtime isolation, REST/GraphQL API security, AI-powered threat detection, deepfakes, Identity and Access Management (IAM), Zero Trust architecture (NIST SP 800-207), DevSecOps CI/CD integration, and software supply chain security (SBOMs).

---

## 2. Module Learning Outcomes
Upon completion of this module, students will demonstrate the ability to:
1. Apply the Shared Responsibility Model across major cloud deployment types.
2. Identify security misconfigurations in containerized environments (Docker/Kubernetes).
3. Evaluate modern authentication mechanisms (OAuth 2.0, OpenID Connect, FIDO2/WebAuthn).
4. Explain the core tenets of Zero Trust: verify explicitly, use least privilege, assume breach.
5. Integrate automated static and secret scanning into a continuous integration pipeline (DevSecOps).
