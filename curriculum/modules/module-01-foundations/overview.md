# Module 1: Cybersecurity Foundations

> **Canonical Module ID**: `SEC-MOD01`  
> **Course Level**: Beginner  
> **Total Estimated Duration**: 6 Hours  
> **Prerequisites**: General computer and internet literacy

---

## 1. Module Overview & Pedagogical Scope
Cybersecurity Foundations provides the conceptual bedrock for all subsequent studies in information security. Students explore what cybersecurity truly encompasses beyond popular media depictions, differentiating between administrative governance, technical security engineering, and penetration testing.

Through real-world case studies, students examine core security axioms—specifically the CIA Triad (Confidentiality, Integrity, and Availability)—and master the vital distinction between threats, vulnerabilities, risks, and exploits.

---

## 2. Module Learning Outcomes
Upon completion of this module, students will demonstrate the ability to:
1. Define the core tenets of the CIA Triad and evaluate security controls against each pillar.
2. Differentiate accurately between threats, vulnerabilities, likelihood, impact, and exploits.
3. Map an organization's high-level attack surface across human, physical, and technological vectors.
4. Articulate modern career pathways in cybersecurity (SOC Analyst, Penetration Tester, Incident Responder, GRC Analyst).

## 4. Practical Laboratories Overview
- **`LAB-FOUND-01`**: Cryptographic Hash Verification & File Integrity Monitoring (Tier 1 Localhost CLI). Students compute SHA-256 hashes of test files, verify file integrity, and observe how single-bit alterations produce completely different hash digests (avalanche effect).
